# 04 数据模型

> 字段名与 `src/types/index.ts` 完全一致。原型无后端，数据保存在浏览器 localStorage。

## 一、枚举

| 类型 | 取值 | 说明 |
|---|---|---|
| `FactionId` | `SARK` `VIC` `RI` `TARA` `REU` `SSC` | 六阵营：萨卡兹军事委员会／典范军／罗德岛／塔拉·深池／整合运动／市民自救军 |
| `StatKey` | `manpower` `supply` `morale` | 人力／补给／士气 |
| `CardCategory` | `action` `designated` `faction` | 行动牌／指定牌／阵营牌 |
| `SpecialKind` | `immunity` `cancelCounter` `truce` `revive` `reveal` `stealSupply` `transfer` `coop` `redirect` `exchange` `buyManpower` `declareVictory` | 特殊效果类型 |
| `GamePhase` | `briefing` `handoff` `picking` `council` `resolved` `result` | 对局阶段 |

## 二、实体字段表

### Stats

| 字段 | 类型 | 必填 | 说明 | 示例 |
|---|---|---|---|---|
| `manpower` | number | 是 | 可动员战力 | `12` |
| `supply` | number | 是 | 装备与物资 | `12` |
| `morale` | number | 是 | 凝聚力与合法性 | `6` |

### CardDef（卡牌）

| 字段 | 类型 | 必填 | 说明 | 示例 |
|---|---|---|---|---|
| `id` | string | 是 | 全局唯一；格式 `阵营前缀-编号`（行动牌 `S-01`，指定牌 `S-D1`，中立援助 `G-01`，阵营牌 `FC-01`） | `S-D4` |
| `owner` | `FactionId \| 'GENERIC'` | 是 | 归属；中立援助与阵营牌为 `GENERIC` | `SARK` |
| `name` | string | 是 | 牌名 | `飞空艇升空` |
| `category` | `CardCategory` | 是 | 行动牌／指定牌／阵营牌 | `designated` |
| `round` | number | 否 | 指定牌发放回合（1–7） | `4` |
| `axis` | `Axis` | 否 | 行动牌战略轴；同一手 3 张行动牌的轴互不重复 | `assault` |
| `cost` | `Partial<Stats>` | 否 | 行动牌代价，结算时先扣 | `{ supply: 2 }` |
| `effects` | `Partial<Stats>` | 是 | 对持有者的数值增减 | `{ supply: 3, morale: 3 }` |
| `roll` | `RollSpec` | 否 | 概率结算：`chance` 成功率、`win` 成功收益、`lose` 失败负面；中立援助 `chance` 固定 0.3–0.8 | `{ chance: 0.7, win: { supply: 4 }, lose: { supply: -1 } }` |
| `op` | `OpKind` | 否 | 指定牌行动类型 | `siege` |
| `targetRule` | `'hostile' \| 'any'` | 否 | 指定牌目标规则；本版允许指向任意玩家 | `any` |
| `backlash` | `Partial<Stats>` | 否 | 指定牌落空反噬 | `{ morale: -3 }` |
| `requiresAlly` | boolean | 否 | 行动牌前置要求：必须处于同盟 | `true` |
| `tag` | string | 否 | KEY 标签，可被针对 | `飞空艇` |
| `counterTag` | string | 否 | 针对目标标签 | `生命脊椎` |
| `special` | `SpecialKind` | 否 | 特殊效果 | `immunity` |
| `progress` | number | 否 | 萨卡兹战争进度增量 | `2` |
| `text` | string | 是 | 风味文案 | `死魂灵的躯体升空，战争正式开始。` |

> `RollSpec`：`{ chance: number; win: Partial<Stats>; lose: Partial<Stats> }`。阵营牌 `owner: 'GENERIC'`、`category: 'faction'`，不带 `round`。

### 中立援助（`owner: 'GENERIC'`、`category: 'action'`）

| 字段 | 类型 | 必填 | 说明 | 示例 |
|---|---|---|---|---|
| `id` | string | 是 | 唯一编号 | `G-04` |
| `name` | string | 是 | 牌名 | `巫妖的观望` |
| `axis` | `Axis` | 是 | 战略轴，与其他行动牌一起保证 3 选 2 的轴互不重复 | `intel` |
| `effects` | `Partial<Stats>` | 是 | 基础数值增减 | `{ supply: 2 }` |
| `roll` | `RollSpec` | 是 | 成功率 0.3–0.8；成功取 `win`（原效果），失败只取 `lose`（-1 补给或 -1 士气） | `{ chance: 0.55, win: { supply: 2 }, lose: { supply: -1 } }` |
| `special` | `SpecialKind` | 否 | 特殊效果 | `immunity` |
| `text` | string | 是 | 文案 | — |

> 中立援助并入 `GENERIC_CARDS`，按 `CardDef` 管理；每回合随机抽 1 张，**不占 3 选 2 名额**，默认随回合打出，玩家可主动弃置。

### PlayerState（玩家）

| 字段 | 类型 | 必填 | 说明 | 示例 |
|---|---|---|---|---|
| `id` | string | 是 | `p1`–`p4` | `p2` |
| `name` | string | 是 | 玩家名 | `玩家2` |
| `factionId` | `FactionId` | 是 | 阵营 | `VIC` |
| `stats` | `Stats` | 是 | 当前三项数值 | `{9,8,8}` |
| `warProgress` | number | 是 | 萨卡兹战争进度 | `2` |
| `heldDesignated` | `CardDef \| null` | 是 | 保留的指定牌（上限 1） | `null` |
| `exileUsed` | boolean | 是 | 是否已用掉流亡机会 | `false` |
| `exiled` | boolean | 是 | 是否处于流亡 | `false` |
| `defeated` | boolean | 是 | 是否彻底出局 | `false` |
| `allyId` | `string \| null` | 是 | 盟友玩家 id | `p3` |
| `betrayed` | boolean | 是 | 是否撕毁过盟约（永久失去资格） | `false` |
| `betrayedThisRound` | boolean | 是 | 本回合是否撕毁盟约（用于盟约事件结算） | `false` |
| `nullifiedTags` | string[] | 是 | 曾被成功针对的 KEY 标签 | `['国剑']` |

### Pick（一次选牌结果）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `cards` | `CardDef[]` | 是 | 本回合打出的 2 张阵营行动牌；中立援助未弃置时一并记录 |
| `designated` | `CardDef \| null` | 是 | 本回合实际结算的指定牌 |
| `kept` | `CardDef \| null` | 是 | 保留到下一回合的指定牌（上限 1） |
| `targetId` | `string \| null` | 否 | 指定牌目标玩家 id；可指向任意玩家（包括盟友） |

### LogEntry（战报）

| 字段 | 类型 | 必填 | 说明 | 示例 |
|---|---|---|---|---|
| `round` | number | 是 | 所属回合 | `5` |
| `text` | string | 是 | 战报正文 | `A 以「打击生命脊椎」击穿了 B 的【生命脊椎】` |
| `tone` | `'info' \| 'good' \| 'bad' \| 'counter' \| 'pact'` | 是 | 战报语气，决定颜色；`pact` 用于盟约事件 | `counter` |

### RoundModifier（回合剧情修正）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `round` | number | 是 | 回合序号 |
| `label` | string | 是 | 剧情短标题（如「潜入」「夺剑」） |
| `story` | string | 是 | 剧情描述 |
| `deltas` | `Record<FactionId, Partial<Stats>>` | 是 | 每个阵营的增减益，未列出的键视为 0 |

### GameState（对局状态）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `players` | `PlayerState[]` | 是 | 4 名玩家 |
| `round` | number | 是 | 当前回合 1–7 |
| `phase` | `GamePhase` | 是 | 当前阶段 |
| `activeIndex` | number | 是 | 当前操作玩家下标 0–3 |
| `deck` | `Record<string, CardDef[]>` | 是 | 按玩家 id 区分的阵营行动牌堆 |
| `discard` | `Record<string, CardDef[]>` | 是 | 按玩家 id 区分的弃牌堆 |
| `neutralDeck` | `CardDef[]` | 是 | 中立公共牌堆 |
| `neutralDiscard` | `CardDef[]` | 是 | 中立弃牌堆 |
| `factionCardDeck` | `CardDef[]` | 是 | 阵营牌全局共用牌堆（不按同盟分池） |
| `factionCardDiscard` | `CardDef[]` | 是 | 阵营牌弃牌堆，耗尽后洗回 |
| `factionOffers` | `Record<string, CardDef[]>` | 是 | 结算页各同盟玩家的 2 张阵营牌候选；未结盟玩家无键 |
| `factionPending` | `Record<string, CardDef>` | 是 | 已选定、待下一回合开始前生效的阵营牌 |
| `hand` | `CardDef[]` | 是 | 当前操作者的 3 张阵营行动牌（轴互不重复） |
| `neutralHand` | `CardDef[]` | 是 | 当前操作者抽到的中立援助（1 张，不占 3 选 2 名额） |
| `picks` | `Record<string, Pick>` | 是 | 本回合各玩家选择 |
| `pactEvent` | `PactEventDef \| null` | 是 | 本回合盟约事件 |
| `log` | `LogEntry[]` | 是 | 已归档的历史战报 |
| `roundLog` | `LogEntry[]` | 是 | 本回合战报 |
| `winner` | `FactionId \| null` | 是 | 胜者阵营 |
| `winnerReason` | string | 是 | 判定理由 |
| `createdAt` | number | 是 | 开局时间戳（毫秒） |

### FactionDef / VictoryDef

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` / `code` | `FactionId` | 阵营标识 |
| `name` / `title` / `summary` | string | 名称、别称、剧情摘要 |
| `tier` | `1 \| 2 \| 3` | 剧情强度分层 |
| `accent` / `ring` | string | Tailwind 配色类 |
| `base` | `Stats` | 初始数值 |
| `victory` | `VictoryDef` | `{ title, description, key }` 非对称胜利目标 |

## 三、接口表（src/api/gameApi.ts）

> 原型阶段全部为本地实现，无 HTTP 端点；错误以返回 `null` 或静默处理表示。

| 函数 | 入参 | 出参 | 错误处理 | 说明 |
|---|---|---|---|---|
| `saveGame` | `state: GameState` | `void` | 捕获配额异常，不阻断对局 | 写入 `localStorage` 键 `londinium-protocol-save-v1` |
| `loadGame` | 无 | `GameState \| null` | 解析失败或玩家数 ≠ 4 返回 `null` | 读取存档 |
| `clearGame` | 无 | `void` | — | 删除存档 |

## 四、状态机动作（src/store/gameStore.ts）

| 动作 | 入参 | 结果 |
|---|---|---|
| `startGame` | `names: string[]` | 随机阵营、建牌堆、`phase='briefing'`、写档 |
| `beginRound` | 无 | 应用剧情修正、清空本回合选择、`phase='handoff'` |
| `beginPick` | `index: number` | 抽 3 张阵营行动牌（轴互不重复）+ 1 张中立援助，按回合发放指定牌，`phase='picking'` |
| `submitPick` | `cards, played, kept, targetId` | 记录 `Pick`、更新保留牌、弃置未选牌与未保留的中立援助、推进至下一位或 `council` |
| `formAlliance` | `aId, bId` | 校验资格与 2 对上限后建立双向 `allyId` |
| `breakAlliance` | `id` | 解除双方同盟，发起者 `betrayed=true` |
| `resolve` | 无 | 按固定顺序结算并判胜；为同盟玩家生成 2 张 `factionOffers`，`phase='resolved'` |
| `nextRound` | 无 | 先应用 `factionPending`（下回合开始前生效），再回合 +1；胜者或 R7 后进入 `result` |
| `resume` / `reset` | 无 | 读档续局／清档重开 |
