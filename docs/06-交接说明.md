## 三、启动方式

本机原先没有 Node.js，已下载官方便携版到：

```
C:\Users\35232\.local\share\nodejs\node-v20.18.0-win-x64
```

把上面这个目录加进 `PATH` 后：

```powershell
# 方式一：开发模式（服务端 + 前端热更新，启动后会打印局域网地址）
npm run dev:online

# 方式二：正式模式（单端口 8787，开黑推荐）
npm run build
npm start
```

依赖已安装（`node_modules` 就绪），不需要重复 `npm install`。

其他命令：

```powershell
npm run typecheck  # 类型检查
npm test           # 十三个套件共 375 项（引擎/联机/安全/热座/倒计时/保留/同盟/剧情竞标/盟约/竞标保护/胜负门槛/断线恢复/多标签页）
```

## 三之二、本地热座调试模式

不需要开服务端：首页点「本地热座调试」，或访问 `?local=1`。
它用 `src/net/localServer.ts` 在浏览器内存里模拟服务端，调用的是**同一个** `engine.ts`，
所以调试结论对线上成立。页面底部会出现调试栏，可切换当前操作者、一键全员准备/确认。

历史遗留的 `SetupPage` / `gameStore` / `gameApi` / `HandoffPanel`（旧热座版的独立规则实现）
已在改造中删除，理由见 [docs/03](03-页面与流程.md) 附录。

## 八、已知限制

> v0.3.0 起为四人联机版，以下为当前真实限制。

1. **服务端状态在内存里**：重启服务端会丢失所有进行中的对局（客户端会自动重连，但房间已不存在）。座位保留期拉到 24 小时也没用——进程一重启就全丢，长期运行需接持久化。
2. ~~**无超时 / 托管机制**~~ **已解决**：30 秒决策倒计时 + `autoActFor` 托管；且**全员离线时倒计时冻结**，不会被代打。
3. **无账号体系**：座位身份靠一次性 token（有效期 24 小时，重连与在线时续期），清掉浏览器 localStorage 就回不到原座位。**刷新 / 切屏 / 断线在所有阶段都保留座位**，只有显式「离开房间」才释放。
4. 数值平衡尚未经真人实测，属于首版可玩性验证。
5. 战斗过程无动画与音效，仅以日志文本呈现。
6. 只在 Windows + Node 20.18.0 + Edge 上验证过；Safari、移动端浏览器未实测。
