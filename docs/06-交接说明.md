## 三、启动方式

本机原先没有 Node.js，已下载官方便携版到：

```
C:\Users\35232\.local\share\nodejs\node-v20.18.0-win-x64
```

三种启动方式，任选其一：

1. **双击 `dev.cmd`**（推荐，已内置上述 Node 路径）→ 浏览器打开 `http://localhost:5173`。
2. 临时会话：
   ```powershell
   $env:PATH = "C:\Users\35232\.local\share\nodejs\node-v20.18.0-win-x64;" + $env:PATH
   npm run dev
   ```
3. 若你之后自行安装了 Node 18+，直接 `npm install && npm run dev` 即可。

依赖已安装（`node_modules` 就绪），不需要重复 `npm install`。

其他命令：

```powershell
npm run build     # tsc -b + vite build，已通过
npm run preview   # 预览构建产物
```

## 四、数据与 mock 位置

| 想改什么 | 改哪个文件 |
|---|---|
| 阵营初始数值、胜利条件、配色 | `src/mocks/factions.ts` |
| 敌对／可结盟组合 | `src/mocks/factions.ts` 的 `HOSTILE_PAIRS` / `ALLIANCE_PAIRS` |
| 七回合剧情增减益 | `src/mocks/modifiers.ts` |
| 各阵营专属牌（行动牌 + 指定牌） | `src/mocks/cards/{sark,vic,ri,tara,reu,ssc}.ts` |
| 中立援助（GENERIC 行动牌，含成功率参数） | `src/mocks/cards/generic.ts` |
| 阵营牌（全局共用池，仅同盟可抽） | `src/mocks/cards/factionCards.ts` |
| 盟约事件 | `src/mocks/pacts.ts` |
| 数值上限／流亡上限 | `src/utils/game/resolve.ts` 的 `STAT_CAP` / `EXILE_CAP` |
| 胜利判定 | `src/utils/game/victory.ts` |

改数据后刷新页面即可生效；**旧存档可能因数据变化而不兼容**，点顶栏「重开」清档。

> 手牌体系要点：每回合 5 张（3 张阵营行动牌 + 1 张中立援助 + 1 张指定牌），行动牌 3 选 2；中立援助不占名额、默认打出且可弃置，全部按 0.3–0.8 成功率结算。阵营牌是独立全局共用池，仅当前同盟玩家在结算页获得 2 张候选并选 1 张或放弃，效果在下回合开始前生效（优先于回合修正与盟约事件），第 7 回合结束后不再提供。
