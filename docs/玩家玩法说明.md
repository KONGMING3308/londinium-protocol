# 玩法速览

**四人一台设备，7 回合。看谁先达成自己阵营的目标。**

---

**三个数字**：人力、补给、士气。超过 50 的部分变成战绩分；任何一项归零就崩溃——
第一次崩溃转流亡（回 5/5/5，还能赢），再崩一次出局。

**每回合 5 张手牌**：
- 3 张**行动牌** → 选 2 张打出，代价先扣不退
- 1 张**中立援助** → 接受（有成功率，失败小亏）或拒绝
- 1 张**指定牌** → 打给任意一人（盟友也行），或留一回合

**流程**：交接 → 各自暗选 → 公开结盟/撕约 → 统一结算 → 结算页抽阵营牌（有盟友才有）

**同盟**：只有剧情里合作过的势力能结，最多 2 对；每回合双方各 +1 士气；撕约拿一次性加成，但永远不能再结盟。

**赢法**：第 6、7 回合结束各判一次，先达成者胜。你的阵营要什么，开局简报里写着。

**三句话**：士气是大家的胜负线；指定牌能打盟友；第一次崩溃还有救，第二次没有。
