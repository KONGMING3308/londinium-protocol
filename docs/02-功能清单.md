# 02 功能清单

> 编号全局唯一；P0 验收标准见 `05-验收标准.md`。状态：已实现（原型）／待验证。

| 编号 | 名称 | 描述 | 优先级 | 状态 |
|---|---|---|---|---|
| F-01 | 开局与随机阵营 | 输入 4 名玩家名，从 6 个阵营随机抽 4 个，互不相同且必定至少一对敌对 | P0 | 已实现（原型） |
| F-02 | 战前简报 | 两段式：①公开情报——每人阵营归属、T 级、剧情摘要（胜利条件显示为「本人私下确认」）、本局敌对关系与可结盟组合、第 1 回合剧情；②逐人交接——设备依次传给每位玩家，本人确认后才展开自己的胜利条件与初始数值，杜绝同桌围观 | P0 | 已实现（原型） |
| F-03 | 数值系统 | 人力／补给／士气三维；上限 50；溢出转战绩分；≤0 触发崩溃判定 | P0 | 已实现（原型） |
| F-04 | 回合流程与热座交接 | 7 回合；交接遮挡页 → 暗选 → 盟约窗口 → 结算；每回合 4 人依次操作 | P0 | 已实现（原型） |
| F-05 | 卡牌系统 | 每人每回合 5 张手牌：3 张阵营行动牌（战略轴互不重复，3 选 2）+ 1 张中立援助（不占 3 选 2 名额，默认随回合打出、可主动弃置，成功率 0.3–0.8，失败仅 -1 补给或 -1 士气）+ 1 张指定牌（按回合发放，可指向任意玩家，可保留 1 张或弃置）；牌池耗尽洗回 | P0 | 已实现（原型） |
| F-06 | 流亡机制 | 任一数值 ≤0 时崩溃，可用一次流亡：三项重置 5/5/5，上限压至 12，KEY 牌效果减半，不可主动针对；再次崩溃出局 | P0 | 已实现（原型） |
| F-07 | 胜负判定 | 每阵营非对称目标；仅 R6、R7 结束判定；同回合多人达成按 SARK > VIC > TARA > RI > REU > SSC | P0 | 已实现（原型） |
| F-08 | 针对与 KEY 牌 | KEY 牌带标签；针对牌命中则整张无效并计入被针对标签；免疫／取消／转移可使针对落空；未命中回补 +1 补给；宿敌命中额外 +2 士气（非宿敌 +1）；拉特兰调停仅庇护打出者及其盟友，不再使全场针对失效 | P0 | 已实现（原型） |
| F-09 | 同盟与背叛 | 全桌最多 2 对、每人仅 1 个同盟；仅剧情合作势力可结盟；同盟每回合互援 +1 士气；结盟额外获得阵营牌抽取资格（结算页 2 选 1，下回合开始前生效，第 7 回合后不再提供）；撕毁盟约在针对结算前宣告并立即生效，撕毁者永久失去结盟资格 | P0 | 已实现（原型） |
| F-10 | 剧情修正 | 7 回合固定剧本层，每回合开场按各阵营给出增减益并写入战报 | P0 | 已实现（原型） |
| F-11 | 本地存档与续局 | 每次状态变更写入 localStorage；首页可「继续上次对局」 | P0 | 已实现（原型） |
| F-12 | 对局总览与日志 | 四宫格看板、回合进度、完整战报（最近 40 条） | P1 | 已实现（原型） |
| F-13 | 结算与最终报告 | 回合结算日志、各阵营当前状态、胜者宣告、终局排名 | P0 | 已实现（原型） |
| F-14 | 规则手册页 | 结构化规则：胜负判定、回合流程、数值与生死线、四种牌、结算顺序（分步表）、同盟与背叛、针对与 KEY 标签、六阵营胜利条件、七回合剧情、常见疑问 FAQ；带锚点目录 | P1 | 已实现（原型） |
| F-18 | KEY 机制 | 带 KEY 标签的指定牌是相关阵营的获胜前提：本回合打出且未被击穿才记入 `keyTags`（玩家面板显示「已握有」）；若同回合被「针对 X」的牌命中则记入 `nullifiedTags`，KEY 永久作废。胜利判定要求「已握有 + 未被击穿」同时成立 | P0 | 已实现（原型） |
| F-19 | 战争进度 | 萨卡兹专属第四条进度（0–3，面板常显）：飞空艇升空 +1、生命脊椎 +1、接引阿喃那 +2、阵营牌「战线的推进」+1，均需结算成功；累计 ≥3 且士气 ≥8 获胜 | P0 | 已实现（原型） |
| F-16 | 阵营牌逐人选择 | `factionPickQueue` + `factionPickerId` 驱动逐个交接：默认遮挡，仅当前操作者可见 2 张候选；选定后自动推进；已选名单不显示牌面；`takeFactionCard` 在 store 层断言操作者身份 | P0 | 已实现（原型） |
| F-17 | 出牌代价校验 | 行动牌／中立援助的代价高于当前数值时，卡面标红禁用并提示具体缺口；合计代价超出当前数值时给出红色警告但仍允许提交 | P0 | 已实现（原型） |
| F-15 | 新手引导页 | 面向首次玩家的分步引导：一句话玩法、一回合 4 步流程、三条数值、四种牌、怎么算赢、新手 5 个常见错误；首页引导卡与顶栏均可进入；交接页同步展示该玩家的胜利条件与本回合操作清单 | P1 | 已实现（原型） |

## 依赖关系

- F-04 依赖 F-01 生成对局；F-05／F-08 依赖 F-04 的选牌结果；F-07 依赖 F-03／F-06 的终局状态。
- F-09 的资格由 `src/mocks/factions.ts` 的 `ALLIANCE_PAIRS` / `HOSTILE_PAIRS` 决定。
- F-10 的修正表位于 `src/mocks/modifiers.ts`，调平衡只改此文件。
