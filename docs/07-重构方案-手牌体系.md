## 二、四个牌位的定位

### 1. 行动牌（每回合 3 张，3 选 2）
- 每张牌带一个**战略轴** `axis`，同一轴内的牌不得出现“数值碾压”关系。
- 发牌时**按轴分桶**，保证 3 张行动牌的轴互不相同 → 玩家只能选“走哪条路”，不能选“哪个数字大”。
- 每张牌必须有代价或条件（加 A 减 B、延迟、需要同盟、牺牲手牌等）。
- 3 张全部来自本阵营行动池；中立援助不占这 3 张的名额。

轴定义（六选三）：

| axis | 名称 | 设计取向 |
|---|---|---|
| `assault` | 强攻 | 高人力增量，但扣补给或士气 |
| `logistics` | 补给线 | 补给/转换，短期弱、续航强 |
| `propaganda` | 宣传 | 士气与合法性，通常无即时战力 |
| `convert` | 转化 | 用一种资源换另一种，净收益为正但结构失衡 |
| `intel` | 情报 | 看牌/改目标/使对方免疫失效，不直接加数值 |
| `gamble` | 冒险 | 高方差：命中大赚、失败反噬 |

### 2. 中立援助（每回合 1 张，不占 3 选 2 名额）
- 从中立公共池随机分配 1 张，与 3 张行动牌一起构成手牌，但**不占 3 选 2 名额**。
- **默认随回合打出**，玩家可主动弃置；弃置则不结算、直接进入中立弃牌堆。
- 全部中立援助都带 `roll`：`chance` 0.3–0.8；成功取 `win`（原效果，含 `special`），失败只取 `lose`（-1 补给或 -1 士气）。
- 中立池共 12 张，六轴各 2 张，全阵营共用；耗尽后用中立弃牌堆洗回。
- 结盟向的中立援助保留：`G-11` 中立斡旋（`coop`）、`G-12` 中立义勇军（`requiresAlly`）。

### 3. 指定牌（每回合 1 张，可保留 1 回合）
- 不再是“给自己加数值”，而是**对一位玩家发起的行动**，打出时必须指定目标。
- 可指向**任意玩家（包括盟友）**；`targetRule` 统一为 `'any'`，不再限定敌对阵营。
- 走“宣告 → 对方防御 → 命中/落空”三段：对方可用 `immunity` / `redirect` / `cancelCounter` / `truce` 防御；拉特兰调停只保护打出者与其盟友。
- **命中**：总量 6–8 点等效收益（分两项，不得单项堆满）。
- **落空**：按牌面 `backlash` 反噬 2–5 点，并写入战报。
- 可保留到下一回合（上限 1 张），也可弃置；保留则本回合不结算。

指定牌操作类型 `op`：

| op | 命中效果 | 典型落空反噬 |
|---|---|---|
| `strike` | 目标士气 -4，自身士气 +2 | 自身士气 -3 |
| `raid` | 夺取目标 3 补给给自己 | 自身补给 -3 |
| `siege` | 目标补给 -3，自身战绩 +3（萨卡兹改为战争进度 +1） | 自身补给 -4 |
| `sabotage` | 目标本回合指定牌无效，自身士气 +2（若针对 KEY 标签，则同时使该牌无效） | 自身士气 -2 |
| `incite` | 解除目标与其盟友的同盟，自身士气 +1 | 自身士气 -2 |
| `expose` | 公开目标本回合选牌，并使其防御牌失效；自身补给 +1 | 自身补给 -2 |
| `decisive` | 双方人力对抗：差值 ≥3 则夺 5 补给且目标士气 -3；否则自身士气 -3 | 视为落空，自损 3 士气 |

### 4. 阵营牌（仅同盟，结算页 2 选 1）
- 独立于行动牌池、中立援助池、指定牌池的**全局共用牌池**，不按同盟分池。
- 仅在结算界面、且玩家**当前处于同盟**时出现 2 张候选；未结盟玩家不抽取、不显示。
- 每回合结算完成后选 1 张或放弃；所选牌写入 `factionPending`，**效果在下一回合开始前生效**，优先级最高（先于回合修正、盟约事件等）。
- 效果以增益自己与盟友为主：联军军议、共同粮道、并肩旗帜、密约情报、战线推进、背誓筹码、同盟誓言、共同胜利。
- **第 7 回合结束后不再提供阵营牌**。
- 阵营牌不进入手牌、不占 3 选 2 名额。

### 5. 盟约事件（每回合 1 张，公开）
- 进入盟约窗口时公开一张随机事件，**结算时对所有同盟生效**；无同盟者也有独立条款。
- 事件不进入手牌、不可保留、不可针对。
- 事件池（初版 6 张）：

| id | 名称 | 效果 |
|---|---|---|
| `P-01` | 共同防线 | 所有同盟双方各 +2 士气 |
| `P-02` | 分赃不均 | 所有同盟双方各 -1 士气、+1 补给 |
| `P-03` | 联合军演 | 所有同盟双方各 +3 人力 |
| `P-04` | 情报共享 | 所有同盟双方各 +1 士气、+1 补给 |
| `P-05` | 前线告急 | 无同盟者各 +2 补给；有同盟者不加 |
| `P-06` | 背叛的诱惑 | 所有同盟双方各 +1 人力；本回合撕约者额外 +2 士气 |

## 三、数据结构（`src/types/index.ts`）

```ts
export type Axis = 'assault' | 'logistics' | 'propaganda' | 'convert' | 'intel' | 'gamble'
export type OpKind = 'strike' | 'raid' | 'siege' | 'sabotage' | 'incite' | 'expose' | 'decisive'
export type CardCategory = 'action' | 'designated' | 'faction'

export interface RollSpec {
  chance: number        // 0.3–0.8（中立援助）
  win: Partial<Stats>
  lose: Partial<Stats>
}

// CardDef 关键字段
category: CardCategory
axis?: Axis                 // 行动牌必有
cost?: Partial<Stats>       // 行动牌代价，结算时先扣
roll?: RollSpec             // 概率结算，中立援助全部带
op?: OpKind                 // 指定牌必有
targetRule?: 'hostile' | 'any'  // 本版统一 'any'
backlash?: Partial<Stats>   // 指定牌落空反噬
requiresAlly?: boolean      // 行动牌前置条件
```

```ts
// Pick 结构不变
interface Pick {
  cards: CardDef[]              // 2 张阵营行动牌（未弃置的中立援助一并记录）
  designated: CardDef | null
  kept: CardDef | null
  targetId?: string | null
}

// GameState 新增
factionCardDeck: CardDef[]                 // 全局阵营牌池
factionCardDiscard: CardDef[]              // 阵营牌弃牌堆
factionOffers: Record<string, CardDef[]>   // 结算页候选（仅同盟玩家有键）
factionPending: Record<string, CardDef>    // 已选定、待下回合生效
```

旧字段 `progress` 保留（萨卡兹 `siege` 使用）；`special` 继续用于防御与 KEY 牌；`kind` / `globalEffects` 已移除。

## 四、发牌规则（`src/utils/game/deck.ts`）

```
1. 阵营行动牌：从本阵营行动池按 axis 分桶，随机抽 3 张轴互不重复的牌
2. 中立援助：从中立池随机抽 1 张，单独记录，不占 3 选 2 名额
3. 指定牌：按 round 固定发放（沿用 FACTION_DESIGNATED）
4. 阵营牌：结算页从全局池给每位当前同盟玩家抽 2 张候选，耗尽用弃牌堆洗回
```

实现要点：`axisBuckets(cards)`、`drawByAxis(pool, exclude)`；行动牌与中立援助各自维护洗回机制。

## 五、结算顺序（`src/utils/game/resolve.ts`）

1. **阵营牌**：下回合开始前生效（最高优先级）
2. 回合修正
3. 调停保护（只保护打出者与盟友）
4. 行动牌代价
5. 指定牌目标 / 防御
6. 击穿 / 落空
7. 指定牌命中或反噬
8. 行动牌效果（含成功率判定）
9. 盟约事件
10. 同盟互援
11. 上限 / 流亡

> 结算完成后 R6、R7 判胜；结算页为同盟玩家生成阵营牌候选。撕毁盟约仍在“针对结算前”宣告并立即生效。

## 八、牌量与数值约束

- 每阵营 12 张行动牌：六轴各 2 张；同阵营同轴的两张牌必须方向不同。
- 每阵营 7 张指定牌；中立公共牌 12 张（六轴各 2 张）；阵营牌 8 张（全局共用）。
- 中立援助成功率 0.3–0.8，失败仅 -1 补给或 -1 士气，不再有全场负面。
- 单张行动牌净收益控制在 3–6 点等效，禁止“纯 +5 无代价”。
- 同一 effects/cost/roll/special 组合不得在两张牌中重复。

## 十、验收口径

1. 每回合手牌为 5 张：3 张阵营行动牌（轴不重复）+ 1 张中立援助 + 1 张指定牌；行动牌只能 3 选 2。
2. 中立援助不占 3 选 2 名额，可弃置；成功结算原效果，失败仅 -1 补给或 -1 士气。
3. 指定牌未选目标无法提交，且目标可指向任意玩家（含盟友）；落空反噬写入战报。
4. 仅当前同盟玩家在结算页看到 2 张阵营牌候选；未结盟玩家无该环节。
5. 阵营牌效果在下回合开始前生效，先于回合修正与盟约事件；第 7 回合后不再提供。
6. 阵营牌为全局共用池，不同同盟玩家从同一池抽取，耗尽后洗回。
7. 第 2 回合起可正常推进（回归测试此前 council 空白 bug）。
