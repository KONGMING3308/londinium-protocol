# 03 页面与流程

## 一、页面清单

| 路由 | 文件 | 用途 | 关键交互 |
|---|---|---|---|
| `/` | `src/pages/SetupPage.tsx` | 输入 4 名玩家、开始新局、继续存档 | 填名 → 开始新对局 / 继续上次对局 |
| `/briefing` | `src/pages/BriefingPage.tsx` | 战前简报：阵营、目标、敌我与第 1 回合剧情 | 只读（`revealed` 前不渲染任何胜利条件）|
| `/round` | `src/pages/RoundPage/`（`RoundPage.tsx` + `HandoffPanel` / `PickingPanel` / `CouncilPanel`） | 回合操作：交接 → 选牌 → 盟约 | 依次交设备、暗选 2 张行动牌、处置中立援助与指定牌、结盟／撕约、进入结算 |
| `/resolve` | `src/pages/ResolvePage.tsx` | 回合结算：剧情回顾、日志、四宫格状态、胜负横幅、阵营牌选择 | 同盟玩家选 1 张阵营牌或放弃 / 进入下一回合 / 查看最终结算 |
| `/board` | `src/pages/BoardPage.tsx` | 对局总览与完整战报 | 返回回合操作 |
| `/result` | `src/pages/ResultPage.tsx` | 终局排名与胜者宣告 | 再来一局 |
| `/rules` | `src/pages/RulesPage.tsx` | 规则手册：胜负、流程、数值、四种牌、结算顺序、同盟、KEY 标签、胜利条件、剧情、FAQ | 只读（带锚点目录） |
| `/guide` | `src/pages/GuidePage.tsx` | 新手引导：一句话玩法、一回合 4 步、三条数值、四种牌、怎么赢、新手常见错误 | 只读 |

## 二、跳转关系（文字流程图）

```
Setup(/)
  ├─ 开始新对局 → Briefing(/briefing)
  └─ 继续上次对局 → Briefing(/briefing)
Briefing
  └─ 进入第 1 回合 → Round(/round)
Round（三阶段循环，4 人依次）
  ├─ handoff  交接遮挡页 → 点击「我准备好了」→ picking
  ├─ picking  3 选 2 + 中立援助弃置 + 指定牌处置与目标选择 → 4 人完成后 → council
  └─ council  盟约窗口（结盟／撕约）→ 进入结算 → Resolve(/resolve)
Resolve
  ├─ 同盟玩家：2 张阵营牌候选 → 选 1 张或放弃（效果下回合开始前生效）
  ├─ 未结束 → Round（下一回合，重新 handoff）
  ├─ 产生胜者 或 已到 R7 → Result(/result)
  └─ 任意时刻（顶栏）→ Board(/board) ↔ Round(/round) 往返
Result
  └─ 再来一局 → 清空存档 → Setup(/)
```

## 三、每页元素与交互

### Setup 首页
- 四格玩家名输入（最多 12 字，留空默认「玩家N」）。
- 「开始新对局」：随机分配阵营并写入存档，跳转简报。
- 「继续上次对局」：仅在 localStorage 存在有效存档（4 名玩家）时出现。

### Briefing 战前简报
分两段，目的是让胜利条件成为真正的秘密信息。

**第一段 · 公开情报**（全桌可见）
- 四张阵营卡：玩家名、阵营名、T1/T2/T3 强度、剧情摘要；胜利条件一栏显示「本人私下确认」，不渲染任何目标文本。
- 两组信息：本局敌对阵营数量、本局可结盟组合（由 `canAlly()` 预计算）。
- 第 1 回合剧情标题与描述。

**第二段 · 逐人交接**（本地状态 `stage/index/revealed`，不入存档）
- 依次把设备交给每位玩家：先只显示「请将设备交给 X」，本人点击后才展开自己的阵营卡、胜利条件与三项初始数值。
- 确认后自动遮挡并传给下一位；最后一位确认完毕即调用 `beginRound()` 进入第 1 回合。

### Round 回合页
- **交接阶段**：全屏式遮挡卡，仅显示下一位玩家名与阵营，要求其他玩家不要窥屏。
- **选牌阶段**：
  - 当前操作者与其数值（紧凑面板）。
  - 3 张阵营行动牌网格（战略轴互不相同），选中高亮；最多选 2 张。
  - 中立援助区：1 张随机中立援助，不占 3 选 2 名额；默认随回合打出，可勾选「弃置」不结算。所有中立援助带成功率（0.3–0.8），界面显示成功收益与失败轻度负面（-1 补给或 -1 士气）。
  - 指定牌区：上回合保留牌（若有）与本回合新发牌；按有无保留牌给出不同选项：
    - 有保留牌：打出保留牌并保留新牌／弃置保留牌并打出新牌；
    - 无保留牌：打出新牌／保留到下一回合（本回合不结算指定牌）／弃置。
  - 指定牌打出时需选择目标玩家，可选任意玩家（包括盟友）；未选目标不可提交。
  - 未满足「2 张行动牌 + 指定牌决策」时「确认」按钮禁用。
- **盟约阶段**：
  - 四宫格数值总览与当前同盟对数（x / 2）。
  - 两个下拉选择 A/B 方，校验资格后「缔结盟约」；不合法或已达 2 对时禁用。
  - 每对同盟提供「撕毁盟约」按钮，撕毁者标记 `betrayed` 并永久失去资格。
  - 「进入结算」触发 `resolve()`。

### Resolve 结算页
- 本回合剧情标题与描述。
- 若已产生胜者：金色胜利横幅（阵营名 + 判定理由）。
- 四宫格状态 + 本回合战报；按钮文案随是否终局变化。
- **阵营牌选择：逐人交接 → 选择 → 遮挡**。`resolve()` 结算时按座次生成 `factionPickQueue`，并用 `factionPickerId` 标记当前轮到谁。
  - 队列未空时，页面默认处于遮挡态，只显示「请将设备交给 X」与剩余人数；本人确认后才渲染自己的 2 张候选牌。
  - 选定或放弃后 `takeFactionCard` 自动出队并把 `factionPickerId` 推进到下一位；`pickerId` 变化时 `useEffect` 强制重新遮挡，避免上一位的候选牌残留。
  - 已选定名单只显示玩家名、不显示牌面（保密），效果在下一回合开始前由日志公布。
  - 全局共用牌池，不按同盟分池；所选牌写入 `factionPending`，在下一回合开始前生效，优先级高于回合修正与盟约事件。
  - **store 层断言**：`takeFactionCard(playerId, cardId)` 首先校验 `game.factionPickerId === playerId`，不符直接返回，杜绝替他人选择或伪造玩家 id。
  - 第 7 回合结束后不再提供阵营牌。

### Board 总览
- 回合时间轴、四宫格阵营面板与各自胜利目标、完整日志（限 40 条）。

### Result 终局
- 胜者或无胜者标题、判定理由。
- 按「战绩分 + 三项数值」排序的排名列表。
- 最近 6 条战报摘要、「再来一局」。

### Guide 新手引导
- 面向首次玩家的分步引导，7 个区块：一句话说清（你是谁／做什么／怎么赢）、一回合的 4 件事、三条数值、四种牌、怎么算赢、新手最常犯的 5 个错、下一步入口。
- 入口：首页引导卡、顶栏「新手引导」。
- 交接页同步显示当前玩家的「胜利条件」与「本回合要做的 3 件事」。

### Rules 规则手册
- 十节结构化内容：怎么算赢、一回合流程、数值与生死线、四种牌、结算顺序（11 步分表）、同盟与背叛、针对与 KEY 标签、六阵营胜利条件、七回合剧情、常见疑问 FAQ。
- 顶部提供锚点目录，可按需跳转；规则描述与代码实现保持一致。

## 四、页面与目录对应

页面对应 `src/pages/` 下同名文件；跨页组件在 `src/components/`：`Shell`、`Button`、`StatBar`、`CardTile`、`FactionPanel`、`RoundTimeline`、`LogList`。
